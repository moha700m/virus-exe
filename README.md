# VIRUS.EXE — محاكي فيروس مزحة (تدمير عتاد وهمي)

موقع صفحة واحدة عربي (RTL) يحاكي إصابة جهاز بفيروس يتسبب في انهيار العتاد: تحميل ملف، قراءة حرارية، توقف مراوح، تشقق شاشة، شاشة موت زرقاء، وإطفاء كامل.

- يعمل 100% داخل المتصفح، بدون أي مكتبة أو تثبيت.
- أصوات مولّدة بـ WebAudio (بدون ملفات صوت).
- ملء الشاشة + إخفاء المؤشر => إحساس واقعي.
- خروج بـ `Esc` أو ضغطتين سريعتين.
- متوافق مع الجوال، بلا تمرير أفقي.

## التشغيل

```bash
npx serve .   # أو أي سيرفر ستاتيك
```

## النشر على Vercel

1. ادفع المستودع إلى GitHub.
2. من Vercel: **Add New → Project → Import** واختر المستودع → Deploy (بدون Build، Framework: Other، Output: root).

## الملفات

- `index.html` — الصفحة والواجهة
- `styles.css` — التصميم والتأثيرات (glitch، شقوق، CRT)
- `app.js` — منطق التجربة والأصوات
